Cómo funciona el score: cada partido recibe una puntuación 0–100 por mercado. El motor calcula primero factores estadísticos objetivos (forma, % BTTS histórico, media de goles, solidez defensiva, H2H) y una capa de IA los pondera y redacta el veredicto. En producción, los factores salen de API-Football y el veredicto de tu Claude API (Haiku para el barrido, Sonnet para los partidos top).
Esto es una herramienta de análisis informativo, no una recomendación de apuesta ni una garantía de resultado. Las apuestas tienen valor esperado negativo a largo plazo: juega solo lo que puedas permitirte perder. Juego responsable en España: FEJAR · autoprohibición RGIAJ.
